# RNNoise QA 测试套件

针对 `rnnoise_process_frame()` 的回归验证：500 条噪声+语音混合样本，检查
爆音、延迟一致性、不同块长结果一致性、确定性，外加 3 小时连续运行漂移测试。

## 一键运行

```sh
cd tests/qa
./build_and_test.sh
```

脚本会用当前 `src/` 源码编译静态库，重新生成数据集并跑完所有测试。
模型权重缺失时会自动调用仓库根目录的 `download_model.sh`（需联网，带
sha256 校验）。整个流程约 3 分钟，其中 3 小时音频的长测实际耗时约 1 分钟。

## 测试集

- 数量：500 个 WAV，48 kHz、单声道、16-bit PCM，位于 `dataset/`
- 时长：每样本 1.0–3.0 秒（100–300 帧，每帧 480 采样 / 10 ms）
- 语音：确定性共振峰源（基频 90–200 Hz、三个共振峰、音节幅度包络、
  浊音/清音切换）
- 噪声 8 类：白噪声、粉噪、棕噪、类 babble 多音、单频、扫频、脉冲、
  调幅噪声
- 混合：SNR 在 -10 dB 到 +15 dB 间随机，语音 RMS 0.04–0.16，整体峰值
  限制在 0.95 以内并对首尾各加 10 ms 淡入淡出
- 可复现：每个样本由固定种子 + 样本索引经 SplitMix64 生成；
  `results/manifest.csv` 记录每个文件的全部参数与种子

## 检查项与判据

1. 零爆音（`run_qa.c`）
   - 无 NaN/Inf；无硬饱和（连续两样本钉在满量程）
   - 跳变检测：相邻样本差同时超过中位绝对差的 15 倍和局部 10 ms RMS 的
     6 倍才计为 click
   - 输入本身存在同等级瞬态（脉冲噪声样本）时不计为算法爆音：输出局部
     RMS 必须达到输入局部 RMS 的 3 倍才算伪影
   - 另报告最大过冲（频域滤波振铃可能小幅超过满量程，但不削波）
2. 延迟一致
   - 权威判据：单位脉冲响应，能量峰值所在帧。实测固定为 2 帧
     （960 采样 = 20.00 ms），来源是 2 帧分析窗 1 帧 + 延迟谱合成 1 帧
   - 辅助统计：逐帧能量包络（一阶差分后互相关）的延迟分布，仅作报告
3. 块长一致
   - 流式包装器 `QaStream`（`qa_common.c`）按 1、7、127、256、480、512、
     1024、1921 采样的任意块长喂入同一段信号，内部缓冲到 480 采样再调用
     API；输出与逐帧参考结果逐 bit 比较（浮点完全相等）
4. 确定性
   - 两个独立新建的 `DenoiseState` 处理同一输入，输出逐 bit 一致
5. 长时运行无漂移（`run_long.c`）
   - 单个状态连续处理 1 080 000 帧（3 小时）的循环平稳信号
   - 每 6 分钟一个检查点：新建状态回放 3 分钟历史收敛后，比较最近 6 秒
     输出，统计最大逐样本差和 RMS 差；同时累计 NaN/Inf、削波、全局峰值、
     每帧耗时

## 输出文件（`results/`）

- `manifest.csv`：500 个样本的生成参数
- `per_sample.csv`：每样本的 click、削波、峰值、延迟、块长/确定性失配数、
  每帧耗时
- `summary.txt`：500 样本汇总
- `long_run.csv`：长测 30 个检查点的明细
- `long_summary.txt`：长测汇总

程序退出码为 0 表示所有硬性判据通过，非 0 表示存在失败项。
